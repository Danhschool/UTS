Nguồn: public mod art — textures UI (session, global, …) từ repo 0 A.D. (GitHub).
Đã đặt dưới Assets để dùng Sprite trong Unity (Texture Type: Sprite 2D and UI).

Quan trọng:
- File hud_panels.png (session) là atlas: Sprite Mode = Multiple, mở Sprite Editor để slice
  theo sprites.xml trong repo 0ad: binaries/data/mods/public/gui/session/sprites.xml
- Thư mục ui/global/border, ui/global/modern: viền và nền panel dùng với Image Type = Sliced
  sau khi đặt Border trong Sprite Editor.

Tên thư mục trung tính (ThirdParty_PublicModUiTextures) — không gắn thương hiệu vào đường dẫn asset.
